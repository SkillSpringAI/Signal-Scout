Corroborated guidance used by Signal Scout:

- Gemini Flash first;
- Cloud Run minimum instances at zero;
- budget alerts and bounded public endpoints;
- Gemini 3.5+, one qualifying Google agent framework, and one Google Cloud infrastructure service;
- solve a real problem and show the agent doing work rather than only talking;
- public Cloud deployment proof may be captured without keeping unused resources running indefinitely.

Optional Gemma, Veo, Lyria, bonus content, and social posts remain explicitly deferred until the required submission is frozen.
